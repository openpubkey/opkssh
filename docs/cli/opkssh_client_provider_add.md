## opkssh client provider add

Add your own client ID for an OpenID Provider to the client config

### Synopsis

Add your own client ID for an OpenID Provider to the client config, so that
"opkssh login <alias>" uses it. The client config is created from the default
config if it does not exist. The client ID must also be added to
/etc/opk/providers on the servers that should accept it.

To use your own client ID for a provider that is already configured, such as
the default google provider, pass --replace.

```
opkssh client provider add <alias> <issuer> <client-id> [flags]
```

### Examples

```
  opkssh client provider add google https://accounts.google.com <client-id> --client-secret <client-secret> --replace
  opkssh client provider add keycloak https://keycloak.example.com/realms/opkssh opkssh
```

### Options

```
      --client-secret string   Client secret, required by some OpenID Providers such as Google
      --config-path string     Path to the client config file. Default: ~/.opk/config.yml on linux and %USERPROFILE%\.opk\config.yml on windows.
  -h, --help                   help for add
      --replace                Replace the client ID of the provider with this alias, keeping its other aliases and settings
      --scopes string          Space separated scopes to request (default "openid profile email")
```
